## Design decisions (lead)

- **Launch on the one clock**: the session grid's local anchor goes away
  by construction; a re-press before the grid REPLACES the pending
  ticket (Tracktion's handle, in our words — design only).
- **Stems are pre-routing**: a track stem renders its own chain straight
  to master; only the master bounce follows the graph. Sends are still
  not latency-compensated (T09b's documented gap).
- **Render trim = the offline `maxSec`** over the chains the request
  rendered, so the printed file lines up with the timeline the way live
  playback does; length preserved by zero-padding.
- **PDC arithmetic**: every track is heard `maxSec` after node time, so
  automation reads need no per-track offset; only the SEEN playhead is
  shifted (`playheadSec` during playback), never `currentTransportSec()`
  (recording anchors, automation writes). T16 must confirm this against
  the code before writing.
- **Punch is a placement crop, not an engine feature**: the engine keeps
  recording the whole pass; `placeTakes` crops to the loop window per
  mode; no new `editorStore` state.
- **`.tasmo` migration is forgiving**: a refused edge (cycle, unknown
  bus) is logged and re-homed to master; the project always opens.
