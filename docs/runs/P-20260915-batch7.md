## Design decisions (lead)

- **Routing UI is a new drawer, not the header column** — the header is
  T08d-b's this wave and buses need a home of their own anyway. The
  drawer carries the "buses play live; the bounce still renders to
  master" note until §3.6 step 3b adopts the graph offline.
- **Record records what the transport hears**: `recordPress` starts the
  engine first, then the transport, so the take's `onstart` anchor lands
  at or after the play start; count-in goes through the batch-4
  metronome seam; takes land as clips in one undo step; DAW takes use a
  musical mic profile (AGC / noise suppression / echo cancellation off) —
  the memo profile stays for `MicRecorder`.
- **Render jobs are honest about progress**: a single-context render is
  binary; `chunkUnsafe` on reverb / delay / compressor / owlpad and
  unknown ids gate any future chunking; the queue serialises and can
  cancel queued work, and marks an un-interruptible running job
  cancelled on completion.
- **Gesture boundary at the widget only**: zero `window.addEventListener`
  in the automation gesture path after T08d-b; a control that cannot
  report a boundary keeps a minimal local idle fallback, named.
